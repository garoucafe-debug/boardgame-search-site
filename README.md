# ボードゲームカフェ 検索・紹介サイト

ボードゲームカフェ向けの、ボードゲーム検索・紹介用の静的サイトです。
GitHub Pagesで公開し、Studio.designにiframeで埋め込んで利用することを想定しています。

## フォルダ構成

```
boardgame-cafe/
├── index.html          # 一覧・検索ページ
├── game.html           # 個別ゲーム紹介ページ
├── data/
│   ├── games.json      # ゲームデータ（スプレッドシート未接続時のデモ・オフライン用）
│   └── template.csv    # スプレッドシート管理用テンプレート
├── images/              # ゲーム画像置き場
├── css/
│   └── style.css
├── js/
│   ├── config.js        # スプレッドシート連携設定（公開CSVのURLを設定）
│   ├── data-loader.js   # ゲームデータ読み込み共通処理（CSV/JSON両対応）
│   ├── main.js           # 一覧ページ用
│   └── game.js            # 個別ページ用
└── README.md
```

このサイトは、**Googleスプレッドシートを編集するとサイトの表示も自動的に更新される**仕組みになっています。
スプレッドシートの各行に「貸出可」「貸出不可」を入力するだけで、貸出不可のゲームをサイト上から非表示にすることもできます。

## 1. ゲームデータの追加方法（スプレッドシート自動連携）

このサイトはGoogleスプレッドシートを直接CSVとして読み込む仕組みになっています。
**スプレッドシートを編集して保存するだけで、サイト側の反映作業（JSON変換やpush）は不要**です。

現在使用しているスプレッドシート:
https://docs.google.com/spreadsheets/d/1SLarrRI2t_NJQ-_izrteuX0nuWGtUFLG_YGfhL3JG6c/edit

### 1-1. スプレッドシートの列構成

次の14列を使います（既存の「ボードゲーム管理表」の10列に、サイト表示用の4列を追加した構成）。

```
No., 名前, 正式名称, ジャンル, 推奨プレイ人数, 最大人数, 最少人数, プレイ時間, 対象年齢, 難易度, 紹介文, 画像ファイル名, YouTube URL, 貸出可否
```

- `No.` … ゲームの識別子（連番）
- `名前` … 一覧・詳細ページに表示されるタイトル
- `正式名称` … 正式タイトル。`名前` と異なる場合のみ個別ページにサブタイトルとして表示
- `ジャンル` … 自由記述でOK。実際にシートへ入力した値から一覧ページの「ジャンル」フィルターが自動生成される
- `推奨プレイ人数` … 表示用テキスト（例: `3～4人`）
- `最大人数` / `最少人数` … 絞り込み検索に使う数値。`不明` / `不問` / 空欄はどの人数フィルターにも一致する
- `プレイ時間` … 表示用テキスト（例: `60～120分`）。数値部分を自動抽出してプレイ時間フィルターに使用
- `対象年齢` … 表示用（任意）。個別ページのみに表示
- `難易度` … **「入門」「初級」「中級」「上級」** のいずれか
- `紹介文` … ゲームの紹介文。空欄でも表示されます（「紹介文は準備中です」と表示）
- `画像ファイル名` … Googleドライブの共有リンクを貼り付ける（詳細は「2. 画像の追加方法」を参照）。空欄ならプレースホルダー表示
- `YouTube URL` … インスト動画のURL。空欄なら動画欄は非表示
- `貸出可否` … **「貸出可」または「貸出不可」** を入力。空欄は「貸出可」として扱われる

（任意）入力ミスを防ぎたい場合は、`難易度` `貸出可否` の各列にプルダウンを設定できる
- 列を選択 →「データ」→「データの入力規則」→「条件」で「リストを直接指定」を選び、
  `難易度` 列であれば `入門,初級,中級,上級`、`貸出可否` 列であれば `貸出可,貸出不可` を候補として入力する

### 1-2. スプレッドシートを共有してCSVのURLを取得する

1. スプレッドシート右上の「共有」ボタンをクリック
2. 「一般的なアクセス」を「制限付き」→「リンクを知っている全員」に変更し、権限は **「閲覧者」** にする
   （「編集者」にすると誰でもデータを書き換えられてしまうため、必ず「閲覧者」にする）
3. 「完了」をクリック
4. CSV読み込み用のURLは次の形式で組み立てる（`d/` と `/export` の間がスプレッドシートID）

   ```
   https://docs.google.com/spreadsheets/d/【スプレッドシートID】/export?format=csv&gid=0
   ```

   > ⚠️ 「リンクを知っている全員」に設定すると、そのシートの内容はURLを知っている人なら誰でも閲覧できる状態になります。
   > 個人情報など公開したくない情報は入力しないでください。

### 1-3. サイト側にURLを設定する

1. `js/config.js` を開き、`SHEET_CSV_URL` に1-2で組み立てたURLを貼り付ける

   ```js
   window.SHEET_CSV_URL = "https://docs.google.com/spreadsheets/d/1SLarrRI2t_NJQ-_izrteuX0nuWGtUFLG_YGfhL3JG6c/export?format=csv&gid=0";
   ```

   （現在すでにこの内容で設定済みです）

2. 変更を保存し、GitHubにpushする（手順は「3. GitHub Pagesへのデプロイ手順」を参照）

これで設定は完了です。以降はスプレッドシートを編集するだけで、サイトの一覧・詳細ページへ自動的に反映されます。

### 1-4. 貸出可否で表示・非表示を切り替える

スプレッドシートの `貸出可否` 列を書き換えるだけで、そのゲームをサイトに表示するかどうかを切り替えられます。

- `貸出可` または空欄 → 一覧・詳細ページに表示される
- `貸出不可` → 一覧に表示されなくなり、個別ページ（`game.html?id=...`）にも直接アクセスできなくなる

貸し出し中のゲームを一時的に隠したい場合は、そのゲームの行の `貸出可否` を「貸出不可」に変更し、
返却されたら「貸出可」に戻すだけで運用できます。

### 1-5. スプレッドシートを使わない場合（オフライン・テスト用）

`js/config.js` の `SHEET_CSV_URL` を空文字 `""` のままにしておくと、代わりに `data/games.json` の内容が表示されます。
動作確認用のダミーデータ5件（カタン・パンデミック・ito・ラブレター・宝石の煌き）が入っているので、
スプレッドシートを用意する前の見た目確認や、ローカルでのテストに利用できます。
`games.json` を直接編集する場合も、キー名はスプレッドシートの列名と同じです（下記「データ仕様」参照）。

## 2. 画像の追加方法（Googleドライブを使う場合）

画像はリポジトリに入れず、Googleドライブに置いたファイルをそのまま読み込む方式に対応しています。
スプレッドシートを編集するだけで画像を追加・差し替えできるので、GitHubへのpushは不要です。

1. ゲームのパッケージ画像などをGoogleドライブにアップロードする（横長・4:3〜16:9程度の比率を推奨）
2. アップロードした画像を右クリック →「共有」→「全般的なアクセス」を
   **「リンクを知っている全員」「閲覧者」** に変更する
   - スプレッドシートと同様、この設定がないと画像がサイトに表示されません
3. 「リンクをコピー」で共有リンクを取得する
   （`https://drive.google.com/file/d/xxxxxxxx/view?usp=sharing` のような形式）
4. スプレッドシートの該当ゲームの `画像ファイル名` 列に、そのリンクをそのまま貼り付ける
   - サイト側でGoogleドライブのリンクを自動的に画像表示用のURLへ変換します。リンクを短く加工する必要はありません
5. `画像ファイル名` が空欄の場合は、一覧・詳細ページともに自動で「No Image」のプレースホルダーが表示されます

### 補足：リポジトリ内の `images/` フォルダを使うこともできる

Googleドライブを使わず、従来どおりリポジトリの `images/` フォルダに画像を置く方法も引き続き使えます。
`画像ファイル名` 列にファイル名だけ（例: `catan.jpg`）を入力すると、`images/catan.jpg` を読み込みます。
`http` から始まる値はGoogleドライブ以外の画像URLとしてもそのまま使えます。

## 3. GitHub Pagesへのデプロイ手順

gitコマンドを使わず、ブラウザ操作だけで公開できます。

1. **GitHubアカウントを作成する**（お持ちでなければ）
   - https://github.com にアクセスしてアカウント作成

2. **リポジトリを作成する**
   - 右上の「+」→「New repository」を選択
   - リポジトリ名を入力（例: `boardgame-cafe`）
   - 公開範囲は **Public** を選択して「Create repository」
     （GitHub Pagesを無料プランで公開する場合、Publicリポジトリである必要があります）

3. **ファイルをアップロードする**
   - 作成直後の画面に表示される「uploading an existing file」というリンクをクリック
     （見当たらない場合は、リポジトリ画面の「Add file」→「Upload files」）
   - `boardgame-cafe` フォルダの中身（`index.html`、`game.html`、`data/`、`css/`、`js/`、`images/` など）を
     **フォルダごとではなく、中身を選択して**ドラッグ＆ドロップする
     （`boardgame-cafe`フォルダ自体を1つ放り込むと、`index.html`が思わぬ階層に入ってしまうため）
   - 画面下の「Commit changes」をクリックしてアップロードを確定する

4. **GitHub Pagesを有効化する**
   - リポジトリの「Settings」タブを開く
   - 左メニューから「Pages」を選択
   - 「Build and deployment」の「Branch」で `main` を選び、フォルダは `/(root)` を選択して「Save」

5. **公開URLを確認する**
   - 数分後、Pages画面上部に公開URL（`https://ユーザー名.github.io/リポジトリ名/`）が表示される
   - このURLにアクセスし、一覧ページが正しく表示されるか確認する

> データや画像を更新した場合は、リポジトリの該当ファイルを開いて「Edit」→保存するか、
> 「Add file」→「Upload files」で上書きアップロードすれば、GitHub Pages上のサイトにも
> 自動的に反映されます（反映まで数分かかる場合があります）。
>
> なお `git` コマンドが使える環境であれば、従来どおり `git add` → `git commit` → `git push` で
> 更新することもできます。

## 4. Studio.designへの埋め込み方法

1. **Studio.designでプロジェクトを開く**
   - 検索ページを埋め込みたいプロジェクトを開く

2. **Embedボックスを追加する**
   - 検索ページを表示したいページ／セクションを開き、「Embed」（埋め込み）ブロックを追加する

3. **iframeコードを貼り付ける**
   - 以下のコードの `ユーザー名` と `リポジトリ名` を実際の値に置き換えて、Embedボックスに貼り付ける

   ```html
   <iframe
     src="https://ユーザー名.github.io/リポジトリ名/"
     width="100%"
     height="900"
     style="border:none;"
   ></iframe>
   ```

4. **プレビューで表示を確認する**
   - Studio.designのプレビューを開き、検索ページが正しく表示され、検索・フィルターが動作することを確認する

5. **個別ゲームページのリンクが別タブで開くことを確認する**
   - 一覧のカードをクリックすると、`game.html` が新しいタブで開くことを確認する
   - `game.html` 内のリンク（一覧に戻るボタンなど）もすべて新しいタブで開くことを確認する

   > **補足：** Studio.designのiframe内では、埋め込んだページ内でのページ遷移（同一タブでのリンク移動）が
   > 制限される場合があります。そのため本サイトでは、一覧ページのカードリンクおよび `game.html` 内の
   > すべてのリンクに `target="_blank"` を付与し、常に新しいタブで開くように実装しています。
   > 挙動を変更したい場合は `js/main.js` の `card.target = "_blank"` の行、および
   > `game.html` 内の `<a>` タグの `target="_blank"` 属性を編集してください。

| 列名 | 型 | 説明 |

| 名前 | string | ゲーム名（サイトの一覧・見出しに表示） |
| 正式名称 | string | 正式タイトル。`名前` と異なる場合のみ個別ページにサブタイトルとして表示 |
| ジャンル | string | 自由記述。実際に登場する値からフィルターの選択肢が自動生成される |
| 推奨プレイ人数 | string | 表示用テキスト（例: `3～4人`）。そのままカード・詳細ページに表示 |
| 最大人数 / 最少人数 | number | 絞り込み検索に使う数値。`不明` / `不問` / 空欄はどの人数フィルターにも一致する |
| プレイ時間 | string | 表示用テキスト（例: `60～120分`）。数値部分を自動抽出してプレイ時間フィルターに使用。`不明` はどの時間フィルターにも一致する |
| 対象年齢 | string | 表示用（任意）。個別ページのみに表示 |
| 難易度 | string | `入門` / `初級` / `中級` / `上級` の4段階 |
| 紹介文 | string | 紹介文（空文字可） |
| 画像ファイル名 | string | Googleドライブの共有リンク、`http`から始まる画像URL、または `images/` フォルダ内のファイル名のいずれか（空文字でプレースホルダー表示） |

## スプレッドシートが読み込めない場合

- サイトを開いてもゲームが1件も表示されない場合は、`js/config.js` の `SHEET_CSV_URL` が
  正しいURL（`output=csv` で終わるもの）になっているか確認してください
- スプレッドシート側で「ウェブに公開」が解除されていないか確認してください（再共有すると公開URLが変わる場合があります）
- ブラウザの開発者ツール（F12）の「Console」「Network」タブにエラーが出ていないか確認してください
- 上記で解決しない場合は、`js/config.js` の `SHEET_CSV_URL` を一旦空文字に戻すことで、
  `data/games.json` を使った表示に切り替えて動作確認できます

## 評価・コメントについて

★評価とコメントは、閲覧者のブラウザの **LocalStorage** に保存されます。
サーバー側にデータは保存されないため、別のブラウザ・別の端末からは共有されません。
店舗の共有端末で運用する場合は、その端末に投稿が蓄積されていく仕組みとなります。
